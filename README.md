# GEO Audit Master Prompt — vibecoding + multi-LLM orchestration

A reproducible, copy-paste **Master Prompt** to audit and implement **GEO (Generative Engine Optimization)** — your brand's visibility inside AI answer engines like **ChatGPT, Gemini, Perplexity, Claude, and Google AI Overviews**.

GEO is the discipline of getting cited by AI engines, the way SEO got you ranked by search engines. As most queries shift to zero-click answers generated by LLMs, the question stops being "do I rank?" and becomes "does the AI cite me, and what does it say?". This repo gives you a single artifact — [`master-prompt.md`](./master-prompt.md) — that turns that audit into a repeatable, agent-driven workflow.

## What is this

Auditing AI visibility by hand is expensive: dozens of prompts across four engines, cross-referencing schema against visible content, checking Wikidata and the Knowledge Graph, normalizing entities, building spreadsheets. A senior analyst can burn a week on a single pass.

This repo collapses that into one prompt you hand to a coding agent (Claude Code with tools connected, or any MCP-capable agent). The prompt runs **five sequential waves** over a target domain — from technical foundation to agent-readiness — and each wave ends with an explicit **gate** you must pass before moving on.

The companion idea is **vibecoding**: you program by describing intent in natural language and let the agent generate, run, and iterate the code. You stop typing every line and start reviewing diffs and correcting course. It is an acceleration of execution, not a replacement for judgment — over-automating without a thesis produces volume that quality filters learn to discard.

## How it works

GEO implementation is data engineering disguised as marketing: crawl your own site, compare schema to visible content, monitor who the AI cites, normalize entities, generate valid JSON-LD at scale. The leverage comes not from one large model doing everything, but from **orchestrating different models in the roles they are best at**:

| Model | Role |
| --- | --- |
| **Perplexity** (sonar-deep-research) | Live research with verifiable citations — anchors claims in sources, reduces hallucination |
| **GPT-4o** | Drafting and copy — meta descriptions, FAQs, title variants where voice and fluency matter |
| **Gemini 2.5 Pro/Flash** | Analysis of large volumes — crawl logs, keyword lists, bulk page classification by intent |
| **Groq** (Llama / GPT-OSS) | Ultra-fast classification on LPU hardware — clustering queries, tagging features, entity extraction |
| **Claude** (Opus/Sonnet/Haiku) | Decomposing complex problems, generating pipeline code, and critically reviewing other models' output |

An orchestration layer receives the request, picks the right model by **cost, latency, and reasoning need**, routes the task, and integrates the results. Frameworks like LangChain, LangGraph, AutoGen, and CrewAI give the multi-agent structure (state, roles, routing).

The execution surface is **vibecoding with Claude Code + MCP**:

- **Claude Code** as the primary agent — it decomposes the problem, writes the code, and reviews its own output.
- **MCP (Model Context Protocol)** to connect data the way Anthropic wired eleven financial data providers behind a single agent surface. You build a growth MCP server exposing named providers — `search_console_provider`, `analytics_provider`, `crawler_provider`, `ads_provider`, `crm_provider` — and the agent queries them on demand instead of you pasting data into giant prompts.
- **Skills as Markdown** — encode your GEO playbooks, internal frameworks, and brand-voice rules as Markdown skills so they become the agent's stable context.

Define agents by **function, not by channel**: an Entity Auditor Agent, a Citation Monitor Agent, a Schema Designer Agent. Functions are stable; channels change.

## Usage

1. **Set up the surface.** Use Claude Code as your audit agent; optionally Cursor to build and version the scripts with repo context.
2. **Connect data via MCP**, not copy-paste. Stand up a growth MCP server with the named providers above so findings stay auditable.
3. **Encode playbooks as skills** (Markdown) — how you grade a YMYL page, how you prioritize technical issues, your brand voice.
4. **Run the Master Prompt.** Paste [`master-prompt.md`](./master-prompt.md) into the agent, replace the `[DOMAIN]` placeholder, and let it execute the five waves. Treat each wave's gate as a hard stop.
5. **Implement with pull requests.** The agent generates diffs (schema, headings, answer capsules, robots.txt) and opens a PR with a full log. CI validates the JSON-LD. **Critical pages and any sensitive claim require human review before merge.**

The prompt lives here:

```text
master-prompt.md
```

Reproduce the structure, do not copy blindly. The value is in the **output gate of each wave** and in forcing every finding to cite the evidence it observed.

> Epistemic honesty is part of the prompt itself: correlation is not causation in GEO. Mention Rate can move from a refresh, off-site seeding, an LLM algorithm change, or all of them at once. Run controlled tests; never sell a technical shortcut as a silver bullet.
